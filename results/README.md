# Evaluation results

Everything in this folder is generated by `evaluate.py` from the trained
model's predictions on the held-out test split. No metric is typed by hand.

| File | Contents |
|---|---|
| `model_metrics.json` | accuracy, macro/weighted precision, recall and F1, top-3 accuracy, per-class scores, confusion matrix |
| `metrics_summary.json` | compact metrics used by the website |
| `classification_report.txt` | scikit-learn report for all 16 classes |
| `classification_report.csv` | the same report in CSV form |
| `class_wise_performance.csv` | support, correct, precision, recall, F1 and mean confidence per class |
| `confusion_matrix.csv` | raw 16 × 16 count matrix |
| `confusion_matrix_normalized.csv` | row-normalised confusion matrix |
| `test_predictions.csv` | every test image with true class, prediction, confidence and correctness |
| `accuracy_curve.png` | training vs validation accuracy |
| `loss_curve.png` | training vs validation loss |
| `confusion_matrix.png` | annotated confusion-matrix figure |
| `class_f1_scores.png` | class-wise F1 bar chart |
| `sample_predictions.png` | correctly classified test leaf from each plant |
| `training_history.json` | epoch-level training history |
| `training_head_log.csv` | Keras CSV logger during head training |
| `model_summary.txt` | architecture and parameter summary |

The website's **Model performance** page reads these artefacts directly. If
they are deleted, it displays an explicit "run evaluate.py" message rather
than invented values.
