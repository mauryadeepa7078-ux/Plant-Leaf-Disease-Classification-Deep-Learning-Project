# Model files

The final trained model is included in this repository so the website can be
run immediately after cloning. Intermediate checkpoints, ImageNet weights and
feature caches are intentionally excluded because they can be regenerated by
`train.py`.

## Generate the model

```powershell
python scripts/download_dataset.py
python dataset_prep.py
python train.py
python evaluate.py
```

The final model is written to:

```text
models/leafguard_mobilenetv2.keras
models/leafguard_mobilenetv2.onnx   # generated by scripts/export_onnx.py
```

The ONNX copy uses the same trained weights but runs without TensorFlow. It is
the backend used on Render because it fits comfortably in a 512 MB instance.

```powershell
python scripts/export_onnx.py
```

Supporting files written by `train.py`:

| File | Purpose |
|---|---|
| `class_names.json` | class order used by the 16 output neurons |
| `label_map.json` | display label and PlantVillage folder → index maps |
| `preprocessing.json` | input size, colour mode and normalisation record |
| `model_metadata.json` | training mode, epochs, validation accuracy, timing |
| `best_head.keras` | best classifier head checkpoint |
| `mobilenet_v2_imagenet_weights.h5` | cached ImageNet backbone weights |
| `feature_cache_*.npz` | cached frozen features (development speed-up) |

## Architecture

```text
Input 224 × 224 × 3 (RGB, 0–255)
  → training augmentation (no-op at inference)
  → Rescaling to [-1, 1]
  → MobileNetV2 backbone (ImageNet, frozen)
  → GlobalAveragePooling2D (1,280 features)
  → BatchNormalization
  → Dense 256, ReLU, L2(1e-4)
  → Dropout 0.40
  → Dense 16, softmax
```

The full model is saved as one `.keras` file, including the backbone, head and
rescaling layer. This guarantees that the web app uses exactly the same
preprocessing as training.

## Why feature extraction instead of full fine-tuning?

The reference machine is CPU-only. Back-propagating through the full
MobileNetV2 graph took roughly 29 seconds per 32-image batch, making a normal
fine-tuning schedule impractical. Frozen-backbone feature extraction with one
randomly augmented copy per training image is a standard and genuine form of
transfer learning. It trains a classifier on the actual 4,000-image dataset,
uses training-only augmentation, early stopping and checkpointing, and is
documented here rather than hidden.
